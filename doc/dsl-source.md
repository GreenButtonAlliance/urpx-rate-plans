# Filings authored as Clojure source

The Seattle City Light documents and PG&E Schedule E-TOU-C with its medical baseline modifier are generated from Clojure source under `src/rate_plans/`, written with `urpx.dsl`; every other document in the corpus is committed JSON-LD. The design below is the direction for the rest of the corpus; [dsl-corpus-generation.md](./dsl-corpus-generation.md) is the plan for converting it. The source states a filing the way its tariff does: rate tables keyed by effective date, a table of time-of-use brackets, a holiday list. The generated JSON-LD is committed and remains what the corpus publishes; the gate regenerates it and requires every generated document to state the same RDF as its committed file. The same RDF in different bytes is drift, which `python3 dev/check_generated.py --write` fixes.

## Evidence

The Seattle City Light documents (RTC and RTS for each year, and the residential-suburban modifier) generate from one source tree, and the gate checks them against their committed files on every commit. The source is mostly tables copied from the ordinance's year columns.

Every corpus document round-trips through clj-urpx RDF-identically when emitted with its own @context over `urpx.emit/default-context`. With its own @context alone, a document whose @context does not declare `urpx:holidayDate` loses that datatype on values typed inline.

## Requirements

1. Generated equals committed. The gate fails on any document whose regenerated bytes differ from the committed file.
2. Typed definitions. Every definition is made with one macro, `defurpx`, naming its kind with a keyword. The value is validated against that kind's Malli schema when the namespace loads; a failure names the file, the line of the form, and the path to the bad value inside it.
3. Generation by kind. Each definition's kind is in its var metadata; `(defs-of-kind kind nses)` returns the definitions of a kind in the namespaces given, and the generator writes every `:document` among them. There is no manifest of documents and no global registry.
4. Shared data is keyed by the date it takes effect and read as of each version's date. It is never edited in place, so an older version regenerates unchanged after a newer one is added.
5. A reference to a node in another document is its keyword, declared under `dsl-scope`'s `:outside` with its `@type`, so the scope checks it against its slot's range. A modifier names its base plan's Prices and tiers through the same function the base uses to mint them.
6. A sentence that restates table facts (rates, hours, multipliers) is generated from the tables. Other prose is a template filled from the definitions.
7. Unknown keys refuse. A misspelled key is an error, not a silently kept property.
8. Pretty-printed source, one form per line unless a form is short; `clj-kondo` clean.

## defurpx

```clojure
(defurpx :rates rts-rates
  "SMC 21.49.030.B as amended by Ordinance 127473, page 11; cents per meter
   per day (base) and per kWh, one entry per column 'Effective January 1, <year>'."
  {"2026-01-01" {:base-service-charge 39.45M :peak 16.32M :mid-peak 14.28M :off-peak 8.16M}
   "2027-01-01" {:base-service-charge 55.18M :peak 17.02M :mid-peak 14.89M :off-peak 8.51M}
   "2028-01-01" {:base-service-charge 77.22M :peak 17.86M :mid-peak 15.63M :off-peak 8.93M}})
```

`(defurpx kind name doc? value)` validates the value against `(kind-schema kind)`, a multimethod whose `:default` refuses an unknown kind, then expands to a `def` whose var carries `{:urpx/kind kind}`, the docstring, file and line. Validation runs at macroexpansion, before the `def`, so a failed re-evaluation interns nothing. Kinds that clj-urpx defines are qualified `:urpx.kind/*`; the corpus's kinds are qualified in its own namespaces. A malformed row fails at load:

```
Invalid :rates bad-rates/rtc-rates (bad/bad_rates.clj:4)
  at ["2027-01-01" :peak]: 16.9 should be a BigDecimal with 2 decimal places, e.g. 16.10M
  at ["2028-1-1"]: "2028-1-1" should be a yyyy-mm-dd string
```

## Kinds

| Kind | Holds |
|---|---|
| `:utility` | identity: prefix, legal name, EIA id |
| `:source` | a source document: file, URL, retrieval date, pages |
| `:holidays` | holiday names and rules, observance, dated observed days |
| `:tou-periods` | period keys, labels, names |
| `:tou-brackets` | rows of period, days, start, end, holiday treatment |
| `:rates` | rates per effective date |
| `:percentages` | multipliers per jurisdiction per effective date |
| `:undergrounding` | per-kWh charges per jurisdiction per effective date |
| `:jurisdictions` | jurisdiction keys and names |
| `:description` | prose templates and dated notes |
| `:document` | one plan or modifier: identity, versions table, references to the kinds above |
| `:filings` | per version: retrieval date, sheets spanned, advice letter, decision, change reason |
| `:dollars` | figures as the tariff prints them, keyed by charge, tier or year, per effective date |
| `:seasons` | season keys, names, months |
| `:tou-tiers` | time-of-use tiers with their standard names and brackets |
| `:charges` | rows of charge, name, charge type, category, bill portion, ledger, price set, period |
| `:ledgers` | ledger keys, names, types, metric inputs |
| `:income-tiers` | income tiers and the programs that select each |
| `:baseline-quantities` | baseline quantities per territory, code and season, per effective date |
| `:climate-credit` | a per-household credit and its bill months, per effective date |
| `:discountable` | the subtotals a discount program applies to, per effective date |
| `:coverage` | a coverage evaluation per effective date: free text, or the filing's deferrals |
| `:programs` | program keys, names, program types |
| `:advice-letters`, `:decisions` | the filings and decisions a schedule cites, by number |

SCL needed the kinds through `:document`; PG&E E-TOU-C added the rest. Demand charges add kinds when the first utility that has them is ported.

## Layout

Source lives under `src/rate_plans/`, following the namespace-to-path rule and mirroring the corpus. The generic namespaces know nothing about a utility.

| Namespace | Holds |
|---|---|
| `rate-plans.defs` | the corpus's kinds, `:rate-plans.kind/*`, and the date-keyed lookups (`as-of`, `effective-key`, `since`) |
| `rate-plans.urpx` | URPX building blocks over `urpx.dsl`, literal builders (`xsd-time`, `xsd-date-time`, `xsd-gmonth`, `literal-list`), amount formatters (`plain`, `amount`), templates (`fill`), and writing a package or an @graph |
| `rate-plans.tou` | a time-of-use rate plan expanded from its tables, and hours in words (`time-range`, `hours-phrases`) |
| `rate-plans.words` | numbers, lists and dates in words |
| `rate-plans.alternatives` | a modifier whose customer chooses one alternative along one dimension |
| `rate-plans.gen` | the generator |
| `rate-plans.us.wa.scl.common` | what every SCL schedule shares |
| `rate-plans.us.wa.scl.rtc`, `.rts`, `.residential-suburban` | one schedule each |
| `rate-plans.us.ca.pge.common` | what PG&E's schedules share: identity, programs, advice letters, decisions, the Rule 19 medical quantity |
| `rate-plans.us.ca.pge.e-tou-c` | Schedule E-TOU-C, with the Vintaged PCIA modifier its documents carry |
| `rate-plans.us.ca.pge.e-tou-c-medical-baseline` | the Rule 19 modifier over each E-TOU-C version |

General helpers live in the shared namespaces: `rate-plans.defs`, `rate-plans.urpx`, `rate-plans.tou` and `rate-plans.words`. A per-schedule namespace holds only that schedule's tables and builders. Before adding a helper, search the shared namespaces for one that already exists, with `clojure -M:xref` (`init`, then `who-calls`, `who-references`, `unused`) and with `apropos` and `ns-publics` in the nREPL.

`corpus.json` lists these files as the kind `clojure-source`, under its own root `src`, and the generator loads every namespace of that kind.

| Command | Does |
|---|---|
| `clojure -M:generate [out]` | writes every version of every `:document` to `<out>/<corpus path>`; `<out>` defaults to a new temporary directory |
| `python3 dev/check_generated.py` | the gate's check: each generated document states the same RDF as its committed file; on a byte mismatch `dev/rdf_hash.py` reports DIFF when the RDF differs, a regression (exit 1), and FORMAT when only the bytes do, drift (exit 2) that `--write` fixes |
| `python3 dev/check_generated.py --write` | writes into the tree each generated document whose bytes differ, then checks |
| `clojure -M -m test-dsl-validation` | each invalid fixture under `dev/fixtures/dsl/` fails to load with an error naming its file, line and bad values |

`clj-kondo --lint src` reads the `defurpx` hook clj-urpx exports, copied into `.clj-kondo/imports` with `clj-kondo --lint "$(clojure -Spath)" --copy-configs --skip-lint`.

## What goes to clj-urpx

In clj-urpx: `defurpx` and the kind multimethod (`urpx.defs`), and the clj-kondo hook it exports. To move there: fixes for the gaps below.

Here: the utility and schedule namespaces; the kinds `:utility`, `:source`, `:document`, `:holidays`, `:rates`, `:percentages`, `:jurisdictions`, `:undergrounding` and `:description`; the date-keyed lookups (`as-of`, version dates); the TOU and alternatives expansion helpers; the generator entry point; and the gate's equality check. A kind or helper moves to clj-urpx only when it proves general across utilities, and then at this repo's request.

## Gaps in urpx.dsl 0.39.0

Each has a working workaround in the SCL source.

| Gap | Workaround |
|---|---|
| `dsl-scope` local ids drop their prefix | build every `@id` as a full CURIE |
| two keywords in one scope (`:scl/summer`, `:pge/summer`) yield the same `@id` with no error | full CURIEs |
| a qualified keyword value inside a scope is read as a local reference, so `:urpx/allDays` throws | vocabulary values as plain keywords converted to references |
| `condition-expression` rejects short keys (`:root-node`): `alias-map` reads the wrapped schema without dereferencing it | dereference before deriving aliases |
| unknown keys are kept silently | refuse any key that is neither a schema key nor its alias |
| `urpx:offeredBy` is in no version schema | passed through unvalidated |
| no builder for `ComparisonNode`, `UtilityOperator`, `OrganizationIdentity`, `OrganizationName` | raw maps |
| `{:jsonld/list [...]}` emits `@list`, but no helper builds it and no schema checks it (`hasPossibleValues`) | literal `@list` maps |
| a double such as `0.1610` emits `"0.161"` | BigDecimals with explicit scale; builders will refuse doubles in xsd:decimal fields |

## Scope references

`dsl-scope` stays, reworked: the caller supplies the function from keyword to `@id` (by default the keyword's namespace and name as a CURIE), a repeated `@id` refuses, and keyword references resolve when the scope exits, with one error listing every unresolved key and the builder that used it.

## Acceptance

The SCL documents are generated from `src/rate_plans/us/wa/scl/` and the E-TOU-C documents from `src/rate_plans/us/ca/pge/`, and `dev/check_generated.py` requires each to state the same RDF as its committed file. Its scope is every filing whose `tariff.toml` records `[generation]` with `generator = "urpx.dsl"` ([dsl-corpus-generation.md](./dsl-corpus-generation.md#provenance)): a committed document in such a filing that is not generated fails as MISSING, a generated one with no committed file as EXTRA, one whose filing's `[generation]` does not name its `:document` var as UNRECORDED, an entry that writes nothing in its filing as STALE, a source path that does not exist or omits an entry's namespace as NOSOURCE, a hash that cannot be computed as NOHASH, and differing RDF as DIFF. The same RDF in different bytes is FORMAT, which is drift (exit 2): the pre-commit hook prints it without blocking, and `dev/gate.sh` reports it as drift. It runs in `dev/gate.sh --fast` against the working tree and in `dev/check_all.py`, which `dev/gate.sh --full` runs and the pre-commit hook runs against the staged tree.
