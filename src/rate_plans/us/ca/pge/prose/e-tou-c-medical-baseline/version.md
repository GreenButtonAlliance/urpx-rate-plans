PG&E Electric Rule 19, Part A: "The Standard Medical Baseline Quantity is {quantity} kWh per day (approximately) year-round." Schedule E-TOU-C Special Condition 5 (Sheet 6, Cal. P.U.C. Sheet 61129-E): "Standard medical quantities are added to the baseline usage from Special Condition 1 to increase the maximum level of usage subject to baseline (Tier 1) rates." Its heading names the two results: Code M, Basic Plus Medical Quantities, is Code B plus the medical quantity, and Code S, All-Electric Plus Medical Quantities, is Code H plus it.

This version adds {quantity} kWh per day to the Tier 1 upper bound and the Tier 2 lower bound of {base}, and {multiple} kWh per day, four times {quantity}, to the Tier 2 upper bound and the Tier 2 Continued lower bound, because Tier 2 ends at four times the baseline quantity and the medical quantity is part of the baseline. The base version's ladder ends Tier 2 at four times the Special Condition 1 quantity, the Tier 2 that Schedule E-1 prints as "Tier 2 Usage (101% - 400% of Baseline)"; no E-TOU-C sheet states the 400 percent figure, which the base version's manifest records as a deferral. The quantity is the same in every baseline territory, code and season, so each of the {brackets} urpx:ServiceBracket here names one base tier with urpx:adjustsServiceTier and no territory, code or season, one for each of the four bounds, because the base tiers carry season on their own brackets; the Code B or Code H cell selected on the base decides which bound moves.

Rule 19 Part A also states that "The Standard Medical Baseline Quantity used for automated billing is calculated using the unrounded quotient of the following equation: 6,000 kWh per year divided by 365 days. Any billing that requires hand calculations will use {quantity} kWh per day." The quotient (16.438356...) has no terminating decimal form, so this version carries {quantity}, the figure Rule 19 prints.

Customers receiving a medical baseline allowance do not pay the Wildfire Fund Charge (Sheet 1, Cal. P.U.C. Sheet 61124-E, and Special Condition 11, Sheet 10, Cal. P.U.C. Sheet 61133-E: the charge "applies to all retail sales, excluding CARE and Medical Baseline sales"), so this version also carries an exemption Price at urpx:multiplier -1 over {wildfire-fund}, the shape pge:d-care uses.
