## Caveats

- **Source of truth.** This list is derived from `[modeling].complete` in each `tariff.toml`. The flag is hand-curated by the modeler at the time the filing is written; it asserts only that the source PDF was fully captured in the JSON-LD, not that the filing has been independently reviewed (`[review].status` tracks that axis separately).
- **Per-directory granularity.** When a `versions/<date>/` directory contains both a base RatePlan and an inline `RatePlanModifier`, both must be deferral-free for the filing to qualify. A directory is one filing, not two.
- **Modifier coverage is a separate axis.** A base RatePlan being ready does not imply that every modifier that legally attaches to it has its own filing — see [`modifier-coverage.md`](./modifier-coverage.md) for that view.
