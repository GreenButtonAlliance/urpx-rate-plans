# Security policy

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/grid-coordination/urpx-rate-plans/security/advisories/new) for this repository, rather than in a public issue. Include the affected commit or file, a description, and steps to reproduce.

Report errors in rate-plan data in a public [issue](https://github.com/grid-coordination/urpx-rate-plans/issues).

Fixes are made on `main`.
